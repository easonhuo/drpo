# DRPO ICLR 2027 mechanical port

This directory defines the **format-only ICLR 2027 port** of the active full DRPO manuscript.

- Task / claim: `MANUSCRIPT-ICLR2027-PORT-01`
- Base commit: `8b0616cf0f887f86ec04e398a7604c3d3940aa5d`
- Scientific/content source: `paper/iclr2027/manuscript_source.tex`
- ICLR source is maintained independently from the frozen ICML source.
- Official ICLR 2027 style archive: `https://media.iclr.cc/Conferences/ICLR2027/iclr-2027-style-files.zip`

## Hard content lock

This first port is intentionally mechanical. The abstract, main text, section titles, equations, theorem/proposition text, captions, table text and values, citations, appendices, bibliography entries, and figure assets must remain unchanged. The only permitted transformations are template plumbing: replacing the ICML wrapper/title machinery with the ICLR 2027 wrapper, changing the bibliography *style selector* from `icml2026` to `iclr2027_conference`, and anonymous-review formatting supplied by the official ICLR style.

`generate_iclr.sh` verifies a byte-for-byte canonical body lock from `\\begin{abstract}` through the end of the appendix after normalizing only the bibliography-style selector. It also verifies that the dedicated ICLR source Git blob is the expected blob before generating anything; the ICML manuscript source is not read or modified.

## Build

From the repository root:

```bash
bash paper/iclr2027/build.sh
```

The build downloads the official ICLR 2027 style archive, generates an ICLR wrapper without editing the manuscript source, copies bibliography and figure assets byte-for-byte, compiles the paper, and produces:

- `paper/iclr2027/release/main.pdf`
- `paper/iclr2027/release/main.tex`
- `paper/iclr2027/release/iclr2027_conference.sty`
- `paper/iclr2027/release/iclr2027_conference.bst`
- unchanged bibliography and figure assets
- `CONTENT_LOCK_REPORT.txt`
- build diagnostics and an uploadable `DRPO_ICLR2027_MECHANICAL_PORT.zip`

## Scope of this first PDF

The first PDF is a diagnostic migration, **not a content-optimized submission draft**. Page-limit pressure, float placement, line/table overflow, appendix pagination, and ICLR-specific submission statements are to be audited after the mechanical build. No manuscript wording is changed to solve those issues in this stage.

## Nine-task surprisal-gradient working figure

`MANUSCRIPT-ICLR2027-9TASK-GRADIENT-FIG-01` adds a paper-working figure under `paper/iclr2027/figures/` without wiring it into the content-locked manuscript body or changing the original mechanical-port build.

The 3x3 figure combines the eight-task `EXT-C-E8-MULTITASK-P0-01` development pilot with the separate Countdown `EXT-C-E8-V75` single-seed full-bank gradient probe. These remain external diagnostic evidence, not formal multi-seed method-ranking results.

The eight E8 task means come from `easonhuo/drpo-results@a5541e6487d74988f07a381a837972bdc5d3282c`, run `E8_MULTITASK_P0_FIG1_20260729_01`. Per-task 95% intervals were recomputed post hoc from the frozen raw diagnostics using the original P0 bootstrap contract: `prompt_within_task`, 2000 replicates, seed `161803`, fixed original surprisal-bin assignments, and normalization to the resampled lowest-surprisal bin. The derivation first reproduced the saved per-task means, task-equal aggregate means, and saved aggregate 95% intervals with maximum absolute error `0.0`; the derived result is durably recorded in `easonhuo/drpo-results@a43a6eb73749347f3e3d8e9346702731ec1f09b8`, and the compact checked-in validation record preserves that audit. Countdown uses the already frozen plot-ready CSV `results/FIGURE1_EXTERNAL_GRADIENT/countdown_gradient_deciles_seed100.csv` and its saved puzzle-cluster bootstrap intervals.
