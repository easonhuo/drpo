# D4RL-9 frozen-reference β-TOPR 400k pilot

ID: EXT-H-E7-TOPR-D4RL9-PILOT-400K-01. This is the user-approved single-seed hyperparameter screening follow-up, separate from the preserved 36-cell E7 result. It runs all nine Hopper/HalfCheetah/Walker2d medium, medium-replay and medium-expert datasets, seed 200, β={0.25,0.5,1,2,4}: 45 actor trajectories of 400,000 optimizer updates. No DRPO rerun, advantage refresh, Q2 intervention or gradient-variance study is included.

For each dataset train one shared V critic for 100,000 updates (seed 100, expectile 0.5, validation checkpoint selection as in the existing rebuttal pipeline), then freeze the same centered/scaled TD advantages for all five actors. Actors have no warm start and share seed initialization and minibatch index stream. Both batches are 1024, AdamW lr=0.0003 and weight decay=0.0001, actor/critic norm clips=100/10. The existing DRPO formula and old configs are unchanged.

Let r=exp(logπ(a|s)−logged_logμ(a|s)). Use detached w−=exp(β*min(log r,0)), c=A+−w−A−, and loss=−mean(stopgrad(c)*logπ). Positive coefficients remain A+. β=1 (`topr`) is canonical TOPR weighting adapted to transition-wise continuous-action TD advantages; the other four labels are β-TOPR sensitivity variants with a frozen logged behavior reference. They are not the structured-generation joint-fitted-reference method. Joint tanh-Gaussian action log density sums action dimensions and uses the existing safe action/Jacobian. No fitted μ, ratio floor, weight normalization or β search beyond the five fixed candidates is added. Source: https://arxiv.org/html/2503.14286v2#S3 .

Each task selects its original HDF5 SHA, native logged behavior probabilities, Gymnasium-v4 environment and vendored D4RL-v2 score references through the config tasks map. The three environment observation/action dimensions are 11/3, 17/6 and 17/6. Raw rewards and the existing critic/actor processing are preserved. Evaluate every 10k with 10 episodes, terminal 400k with 20. Primary score is the equal mean of 300k/350k/400k; terminal score is separate. Save raw episode records, actual budgets, diagnostics every 50k, TOPR negative weight quantiles and log-ratio<0 fraction, resolved settings, hashes, logs and recovery checkpoint/index every 10k. Checkpoints stay persistent locally.

This is a one-seed screening pilot, not a multi-seed superiority, convergence or statistically significant result. Seed sample SD is undefined for n=1 and remains empty. β−1 differences use the same dataset and seed, with all curves and failure records retained. Numerical failures, support/variance boundaries and task scores are reported separately; no new task-collapse cutoff is introduced.
